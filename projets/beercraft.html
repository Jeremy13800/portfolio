AEn bref

Le projet en trois phrases.

Le projet

Une application web de catalogue de bières, réalisée en PHP et MySQL avec une architecture MVC.

Ce qui a été construit

Un catalogue consultable par tous, avec comptes utilisateurs, commentaires et tableaux de bord pour l'utilisateur et l'administrateur.

État actuel

Projet antérieur, dont le code source est public sur GitHub.

BContexte

D'où vient ce projet.

BeerCraft fait partie de mes premières explorations : construire une application web complète en PHP, avec une base MySQL et une architecture MVC (modèles, vues, contrôleurs).

CAperçu

À l'écran.

beercraft

DFonctionnalités

Ce que le projet permet.

  • Catalogue : liste et fiche détaillée des bières, catégories.
  • Ajout et modification de bières.
  • Inscription et connexion des utilisateurs.
  • Commentaires sur les bières.
  • Tableau de bord utilisateur et tableau de bord administrateur.
  • Envoi d'images (dossier d'uploads).
  • Fichiers sitemap et robots.
